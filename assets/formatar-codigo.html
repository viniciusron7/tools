Formatar código

Mescle, divida e formate HTML, CSS e JavaScript

Saída

O primeiro HTML vira o documento base. CSS e JS cujo nome apareça em um <link href> ou <script src> são embutidos no lugar da tag; o restante entra no fim do <head> e do <body>, na ordem da lista.

Desmarcado: três arquivos (index.html, styles.css, script.js). Marcado: um arquivo por bloco <style>/<script>, nomeado pelo id quando existir. Scripts com src e blocos que não são JS (JSON, templates) ficam onde estão.

Usa as opções de saída acima. Em HTML, remover comentários também limpa os comentários dentro de <style> e <script>.
